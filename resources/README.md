# Tools and Resources from KASTLE

- `rdflib-starter.py`: provides barebones foundation to begin materialization of data into triples
- [Foundry](https://github.com/kastle-lab/foundry): another materialization tool that parses based on YAML mapping files
- `personas.md `: provides all the personas identified for the user to go through in case the survey was not deterministic for them, they contain personalized learning paths. If you want, take a look at the [questions](./Drawbridge-Onboarding%20Questionnaire.pdf) asked at the survey as well.
- `playground.def` : the container used by KASTLE-Lab containing all dependencies for the tools used. Please take a look at the [playground guide](./playground-technical-requirement-specifications.md) for setting up your system.
- [Programmatically querying a Knowledge Graph](./programatically-querying-a-knowledge-graph.ipynb) : contains code guiding the user on how to query the Knowledge Graph that was created.
- Alternatives to MOMo : If you seek other ways of modeling, exploring, creating a Knowledge Graph please take a look at [The Praxis Initiative](https://the-praxis-initiative.github.io), aiming to bring together the ontology creation community. By taking a look in [Same Data Different Models Tutorial Series](https://github.com/the-praxis-initiative/comparative-ontology-modeling/tree/main/2023), you can explore different methodologies.
